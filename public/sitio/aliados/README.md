# Logotipos de los aliados

Coloca aquí los logos de los siete aliados. Formato preferido: **SVG**
(vectorial, escala sin perder nitidez) o **PNG con fondo transparente**.

Nombres de archivo esperados (así los conecta el sitio automáticamente):

| Aliado                     | Archivo                       |
|----------------------------|-------------------------------|
| Casa Payasa                | `casa-payasa.svg`             |
| Archivo Público            | `archivo-publico.svg`         |
| Mercadillo del Buen Gusto  | `mercadillo-buen-gusto.svg`   |
| Yany Bastidas              | `yany-bastidas.svg`           |
| ARKO                       | `arko.svg`                    |
| Dani Pilates               | `dani-pilates.svg`            |
| Nexo                       | `nexo.svg`                    |

Si algún logo llega en PNG, usa la misma base con `.png`
(ej. `arko.png`) y avísame para ajustar la extensión.
